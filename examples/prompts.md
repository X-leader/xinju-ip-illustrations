# 使用示例

## 单句或短口播

```text
使用 $xinju-ip-illustrations，为下面这句话提出一张配图方案：

传统大模型会生成大量文字，存在速度慢、成本高、结果需要解析、格式不够稳定等问题。
```

## 中文正文

```text
使用 $xinju-ip-illustrations，分析下面这篇文章的认知锚点，按固定模板提出配图方案，并让我选择最终风格：

<粘贴正文>
```

## 指定风格

```text
使用 $xinju-ip-illustrations，为下面这段内容设计配图。
方案确认后使用拼贴漫画风格：

<粘贴内容>
```

## 跳过确认直接生成

```text
使用 $xinju-ip-illustrations，跳过方案确认，直接用手绘线稿风格为下面这句话生成一张 16:9 横版配图：

<粘贴内容>
```

## 真人照片转活动人物

```text
使用 $xinju-ip-illustrations，用我上传且已获授权的真人照片生成迷你人物 IP，并直接替换活动人物。
```

## 已有人物 IP 替换

```text
使用 $xinju-ip-illustrations，把我上传的完整人物 IP 直接设为活动人物，不重新设计人物。
```

## 恢复默认人物

```text
使用 $xinju-ip-illustrations，恢复 Xinju。
```

## 查看当前活动人物

```text
使用 $xinju-ip-illustrations，告诉我当前活动人物是谁，并展示当前活动 IP。
```
