# 手绘线稿风格 DNA

本文件只适用于“手绘线稿”模式。选择“平涂插画”或“拼贴漫画”时，分别读取对应风格 reference；共享的 IP、动作、构图和留白规则仍然有效。

## 一句话

纯白、极简、手绘、留白、克制、怪诞、迷你人物与巨大物件的尺度反差、产品草图感、中文手写感、结构清楚但不说明书。

像一个长期做 AI、产品、设计、开发工具的人，在白纸上随手画出来的一张解释草图。

## 必须

- 生成含人物时同时输入唯一活动身份参考 `assets/ip/active-ip-four-view.png` 与风格母板 `assets/style/lineart-style-board.png`。前者只锁人物身份，后者只锁细线、排线、色点与简洁度；不得复制母板中的示例姿势、局部物件或排布，也不得同时输入 Xinju 备份母板。
- 使用方案中已确认的画幅；默认 16:9 横版。
- 纯白背景：不要米色、暖灰、纸张纹理、渐变、阴影、噪点、复古纸感。
- 黑色手绘线稿为主：细线、轻微抖动、不机械、不矢量、不厚重描边。
- 活动人物固定采用“黑白手绘人物＋单一浅暖肤色＋1–2 个局部身份色”：脸、耳、颈部、手臂和手完整填充统一的浅暖桃肤色；头发、眼镜、服装和鞋严格按 `character-ip.md` 的当前身份锚点简化。不得把人物整体去色，也不得加入腮红、柔和 3D 明暗、发丝高光、空气感皮肤或写实材质。当前人物为 Xinju 时，局部身份色仍固定为中蓝牛仔裤。
- 人物轮廓使用与场景一致的细至中等黑色手绘线，轻微抖动但结构清楚；肤色只是一层平坦、哑光、均匀的局部色面，脸部识别仍由轮廓、眼镜、简化椭圆眼、小鼻点与动作嘴形建立，不能靠立体肤色建模补足。
- 大量留白但主体不能过小：严格执行 `composition-lock.md`；本风格不得另行缩放或改写共享构图。
- 少量中文手写批注：最多 5-8 处，每处尽量 2-8 个字。
- 一张图只讲一个核心动作、结构、状态或隐喻。
- 物件默认只有一个巨大且简单的主轮廓，优先日常物件；内部只保留与活动人物动作和输入输出直接相关的 1–3 处功能结构。不得把多组仪表、轨道、操纵杆、面板或内部机构包装成一个复合机器，也不要用密集排线、螺丝、接口或机械纹路填满物件。
- 结构要自然表达，不要在图上写结构类型名称。
- 角色保持固定身份，但表情与身体语言随动作明显变化；夸张来自受力和因果，不使用通用表情包。
- 角色严格保持当前 `character-ip.md` 记录的头身比例与体积倾向。真人照片转出的角色采用约 2.8–3.1 头高、头大肩窄、短躯干和宽重下肢的成熟迷你骨架；上传的已有 IP 保留其自身比例，不得被强制改成 Xinju。无论哪种来源，都不能退化成幼儿 Q 版或拉回写实成人比例；“迷你”仍主要来自角色与巨大日常物件的尺度反差。

## 颜色

- 黑色：主体线稿、框线、结构、主要文字和主体物件；人物深色身份锚点使用顺向排线形成清楚色块。
- 浅暖肤色：固定用于活动人物可见的脸、耳、颈部、手臂和手；采用单一浅暖桃色平坦哑光填充，黑色轮廓与必要结构线保持清楚，不做腮红、柔光、阴影、高光或体积渐变。
- 身份色：只使用 `character-ip.md` 指定的 1–2 个局部身份色，以轻量平涂叠加同色与纸白排线；不要模拟写实材质。
- 服装与鞋：没有被列为身份色的部分保持纸白，只用少量黑色结构线表达体积。
- 红色：重点批注、问题、情绪点、关键提醒、结果。
- 橙色：主流程、路径、箭头、自动化流向、从 A 到 B 的移动关系。
- 蓝色：补充说明、脑内状态、系统状态、第二层解释、AI/assistant/自动化提示。

当前人物档案指定的轮廓锚点和局部身份色每张都必须保留；皮肤始终使用统一浅暖桃肤色，不能漏填成纸白，也不能扩散到眼白、眼镜、头发、衣物或背景。红、橙、蓝批注色按内容选用，不要求同时出现。颜色要克制，宁可少不要多。

## 绝对不要

- 不要商业插画。
- 不要 PPT 信息图。
- 不要正式流程图。
- 不要课程课件。
- 不要可爱卡通海报。
- 不要儿童插画。
- 不要复杂架构图。
- 不要精致扁平插画。
- 不要科技感 UI。
- 不要真实 App 截图。
- 不要复杂背景、渐变、阴影、纹理。
- 不要把每个节点都解释清楚。
- 不要左上角写“Workflow 流程图 / 系统架构图 / 常见坑 / 路线图”等类型标题。

## 审美方向

要怪诞、创意、有意思、简洁清爽、天马行空。

不要可爱、幼稚、很复杂、死板。
