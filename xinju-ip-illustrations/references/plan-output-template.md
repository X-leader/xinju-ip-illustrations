# 配图方案固定输出模板

本文件只用于新正文配图或短口播配图的第一阶段方案说明。固定的是用户可见的标题、字段顺序、风格选项和结尾数字生成提示；每个字段的具体内容仍须根据当前正文重新设计，不能把示例画面当作通用构图。

## 单张配图模板

严格按下列顺序输出；字段没有内容时写“无”，不要删除字段、改名、调序或另加同级标题。

```markdown
### 配图方案

- **配图位置**：
- **核心表达**：
- **视觉隐喻**：
- **结构类型**：
- **人物表现**：
- **构图设计**：
- **物件**：
- **文字批注**：
- **画幅**：

### 风格选择

1. **手绘线稿**：纯白背景、极简黑色手绘线条、克制身份色与少量红橙蓝批注。
2. **平涂插画**：单一主色调、几何平涂造型、硬边投影与克制空间层次。
3. **拼贴漫画**：有色纸面、半调纸偶、裁切边、叠纸阴影与手写批注。

回复 `1`、`2` 或 `3`，即表示采用上述方案，并按对应风格直接生成。
```

## 字段填写规则

- **配图位置**：写明放在哪句话、口播句或段落之后。
- **核心表达**：只写这张图需要传达的一个判断、状态或转折。
- **视觉隐喻**：说明用哪个现实物件和哪种物理变化表达抽象概念。
- **结构类型**：只选一个主结构：Workflow、系统局部、前后对比、角色状态、概念隐喻、方法分层、地图路线或小漫画分镜。
- **人物表现**：合并说明活动人物的决定性动作、动作引发的表情、身体重心、人物朝向及与物件的接触关系。只要脸部可见，就写明可读嘴形。
- **构图设计**：说明主体分区、信息方向、完整视觉组的中央重心与四周连续留白。Workflow 额外写明流程方向及横版或竖版组织方式，但不向用户罗列内部 QA 百分比。
- **物件**：只按“核心物件：XXX；辅助物：无／XXX”列出，不向用户展开功能零件。选物时优先轮廓简单的日常物件，避免控制台、工作台或多模块机器；内部继续执行 `composition-patterns.md` 的四元素预算、极简物件锁和删除阶梯。
- **文字批注**：单独列出“必须准确呈现”和“可选气氛批注”；没有可选批注时写“可选气氛批注：无”。默认 3–5 处可读短标注，必须文字优先使用 2–6 个汉字的横排短词。
- **画幅**：使用简短格式，例如“16:9 横版”“9:16 竖版”或“1:1 方形”。默认 16:9 横版。

动作、表情、人物朝向、接触关系和构图骨架的近期去重仍按 `composition-patterns.md` 在内部完成，不再作为用户可见字段输出。

## 多图与已选风格

- 多张配图时，依次使用 `### 图 1 配图方案`、`### 图 2 配图方案`；每张都完整保留九个字段。全部方案之后只出现一次 `### 风格选择`。
- 用户已点名风格时，仍列出全部三种，并在对应选项末尾标注“（当前选择）”。
- 结尾数字生成提示保持不变。未收到有效风格编号前停止在方案阶段；收到编号后，该回复同时表示采用当前方案和确认最终风格，立即进入生图，不得再追问“确认方案”。

## 不适用范围

人物替换、恢复 Xinju、展示当前活动人物、已有图片局部修改和用户明确要求跳过方案直接生成，不使用本方案模板。
