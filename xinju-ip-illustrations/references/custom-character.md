# 自定义人物 IP 创建与替换

只处理用户本人或用户明确获授权的真人照片和人物 IP。用户明确上传并要求生成或替换，即视为已经确认本人或授权使用，不重复询问。只记录可见造型，不推断姓名、民族、健康、性取向、宗教等敏感信息。原始照片、私人 IP、人物档案和测试结果不得写入 Skill、案例、风格资产或开源仓库；只保存最终活动母板与当前人物档案。

## 真人照片转活动 IP

1. 只记录可见的身份锚点：发型外轮廓与分区、脸型、眼距与眼角方向、眼核宽高比、是否佩戴眼镜、服装品类与版型、衣物垂坠和体积、鞋型、配饰和整体气质。
2. 忽略照片背景、姿势、镜头畸变、光照、精确肤色与摄影质感。照片身形只帮助理解服装松紧与廓形，不能决定最终写实身材。
3. 明确双参考优先级：`assets/ip/xinju-ip-four-view.png` 是第一参考，只锁共同骨架、体积层级、四视图排布和简化程度；真人照片是第二参考，只锁发型、脸部几何、眼睛关系、眼镜、服装、鞋、配饰与气质。不得复制 Xinju 的男性身份、具体发型、眼镜、白 T、蓝裤或配色，也不得让真人照片把结果拉回写实成人比例。
4. 生成干净的正面、3/4、侧面全身母板，条件允许时加背面。母板不得带场景、文字、动作或装饰。
5. 检查身份、服装、鞋型、四肢和多视角一致性；有硬缺陷时只做一次定向修正。通过后生成完整人物档案，直接覆盖活动人物。

## 上传已有 IP

- 清楚的四视图／多视图：直接设为活动人物，不重新设计。
- 清楚的单张完整 IP：直接设为活动人物，并在档案标记“单视图参考”；不补画未知背面、不把它改成 Xinju。
- 头像、严重遮挡、低清图片或多人图片：要求补充合格图片或明确目标，不自行补画或混合身份。
- 上传图片同时包含场景、文字或其他角色时，只提取目标人物，不继承原图场景、构图、姿势、文字和署名。
- 已有 IP 决定自身头身比、五官、服装、配色和怪诞特征。三种风格只改变线条、色场、纸张与阴影，不得抹掉角色自身设计。

## 共同人物语言

- 真人转 IP 使用约 2.8–3.1 头高的成熟迷你荒诞比例：头宽约肩宽 1.3–1.5 倍，窄肩、短颈、短躯干、压缩四肢、宽重下肢，手与鞋略放大。保留成年人结构与气质，不变成幼儿 Q 版、精致动漫、光滑潮玩、企业吉祥物或写实成人比例。
- 五官小而可读：短上眼睑、单层深色眼核与肤色负空间。眼距、眼角方向、眼核宽高比和眉眼距离必须根据人物变化；无眼镜人物可更柔和略扁，有眼镜人物可适度增大或更直立，避免被镜框吞没。眼核保持中等偏小但清楚，不能缩成针点或小豆点；不画动漫大眼、多层虹膜、明显眼白边框、反光高光、睫毛或妆容。
- 鼻子必须小但可读：正面使用短线或小鼻尖，3/4 视图使用小弧线或楔形，侧面保留克制的鼻梁投影；嘴是短小、中性、随动作变化的简单线形，不画露齿大笑。
- 默认气质克制、认真、略带空白感。荒诞感来自成年人被压缩进迷你骨架、体积错位和物理动作，不靠腮红、卖萌或幼态表情。
- 头发归并成 6–10 组粗厚圆钝发束；保留少量决定版型的衣物褶皱、接缝、纹理与鞋底厚度。避免摄影写实和过度精致。
- 母板使用有粗细变化的黑色轮廓、大块色面、轻微手绘不规则和克制的两级明暗；不得生成扁平矢量娃娃、精致动漫、光滑玩具、企业 3D 吉祥物、皮克斯式面孔或写实人像。
- 日常配图中动作可夸张，但身份锚点、唯一完整人体与可读嘴形不能漂移。

## 跨风格分工

- 人物母板负责“是谁”：比例、脸、发型、眼镜、服装、鞋型、配饰和身份色。
- 风格母板负责“怎么画”。手绘线稿使用单一浅暖哑光肤色与最多 1–2 个身份色，不使用腮红、渐变、明暗和写实皮肤；平涂归并为 3–5 个大色面，不继承摄影光；拼贴转成 2–4 组分层纸片与少量身份色，不能把人物做成线稿贴纸。三种风格都不能把已有 IP 重新设计为 Xinju。
