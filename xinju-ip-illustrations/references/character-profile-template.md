# 活动人物档案模板

替换活动人物时，完整改写 `references/character-ip.md`；只描述当前人物，不保留与其冲突的 Xinju 特征。

```markdown
# 活动人物 IP

## 参考状态

- 来源：真人照片转译 / 用户上传的现有 IP / 默认 Xinju
- 参考完整度：四视图 / 多视图 / 单视图
- 唯一身份图：`assets/ip/active-ip-four-view.png`

## 固定身份锚点

- 人物类型与整体年龄感：
- 头身比例、肩颈、躯干与下肢体积：
- 手掌与鞋的相对体积：
- 发型外轮廓、分区和必须保留的结构：
- 脸型、耳颈与眉形：
- 眼睛几何：眼距、眼角方向、眼核宽高比、眉眼距离及眼镜内可读性：
- 鼻与嘴的简化方式：
- 眼镜：无 / 有；准确轮廓：
- 上装品类、主色、松紧与垂坠：
- 下装品类、主色、松紧与体积：
- 鞋型、主色和鞋底厚度：
- 标志性配饰：
- 手绘线稿肤色：统一浅暖桃色或明确单一替代色；只做平坦哑光填充。
- 手绘线稿保留的 1–2 个身份色：
- 平涂与拼贴可用的 3–5 个身份色：

## 跨风格与动作锁

- 人物母板只决定身份；三种风格不重设计人物。
- 单视图限制：无 / 不得虚构未展示的结构。
- 动作中不可漂移的身份锚点：
- 跨风格身份色映射：手绘 1–2 色 / 平涂 3–5 色 / 拼贴 2–4 色：
- 禁止混入的其他人物特征：
- 可见脸部必须保留小鼻子与清晰短嘴；人体必须是唯一完整的两手两脚结构。
```
